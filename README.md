# resource-prices

Цены на ресурсы для ЛРВ (ПТО ООО «PROBUILD GENERATION»). Используется вместе с нормативной базой [SHNK_GSN](https://github.com/ojbekhabibov-svg/SHNK_GSN) (правила — `SHNK_GSN/_правила_ЛРВ/ПРАВИЛА_ЛРВ.md`).

## Структура
- `прайсы/<год>-Q<квартал>/` — исходные прайсы и каталоги в любом формате (как получены).
- `База_цен.xlsx` — сводная база:
  - «Цены» — позиция, ед. изм., цена без НДС (сум), период, регион, тип источника, ссылка на исходный файл;
  - «Синонимы» — принятые сопоставления «ресурс в норме ↔ позиция прайса» с коэффициентом пересчёта единиц;
  - «Как заполнять».

## Правила применения цен в ЛРВ
1. Приоритет источника: каталог (текущий квартал) → местный рынок → зарубежный рынок. Цены без НДС, в сумах.
2. Сопоставление по смыслу с учётом характеристик (грузоподъёмность, мощность, диаметр, марка); единицы — пересчёт (Т → КГ ÷1000, через массу/плотность — с основанием).
3. При нескольких ценах — актуальный период.
4. Источник в ЛРВ (лист «Ресурсы», кол. F) — кратко: «IV кв. 2026г. г. Ташкент».
5. Цены нет — ячейка цены остаётся пустой.
6. Сопоставления, подтверждённые Ойбеком, заносятся в «Синонимы» и применяются в следующих ЛРВ автоматически.
