# resource-prices

Цены на ресурсы для ЛРВ (ПТО ООО «PROBUILD GENERATION»). Используется вместе с нормативной базой [SHNK_GSN](https://github.com/ojbekhabibov-svg/SHNK_GSN) (правила — `SHNK_GSN/_правила_ЛРВ/ПРАВИЛА_ЛРВ.md`).

## Структура
- `прайсы/каталоги/` — каталоги цен, котировки УзРТСБ, «Прогноз Гидропроект» (маш-ч на 01.01.2026).
- `прайсы/экспертиза/` — цены, рекомендованные экспертизой.
- `прайсы/из_ЛРВ/` — цены ресурсов из ранее составленных ЛРВ / ЛРС.
- `прайсы/README.md` — реестр файлов (содержание, период, регион, НДС).

Единая сводная база не ведётся — цены берутся напрямую из файлов.

## Правила применения цен в ЛРВ
1. **Основное правило — брать максимальную (самую высокую) из найденных цен** на ресурс по всем файлам репозитория.
2. Сравнивать только сопоставимое: тот же ресурс с теми же характеристиками (грузоподъёмность, мощность, диаметр, марка), цены без НДС, в сумах, в одной единице измерения (пересчёт Т → КГ ÷1000; через массу/плотность — с основанием; USD — по курсу ЦБ на дату цены).
3. Источник выбранной цены — кратко в ЛРВ (лист «Ресурсы», кол. F), например «IV кв. 2026г. г. Ташкент»; подробно — в сгруппированных колонках G–L (файл, позиция, исходная цена, коэффициент).
4. Если максимальная цена резко выбивается из остальных (более чем в 2 раза) — применить её, но отметить в колонке «Основание» для проверки.
5. Цены нет ни в одном файле — ячейка цены остаётся пустой.
6. Людские ресурсы: все категории рабочих (рабочие-строители, рабочие-монтажники, доп. перемещение рабочих по трассе и прочие) — **одна и та же цена чел-ч** (максимальная из найденных). Машинисты (в т.ч. доп. перемещение машинистов) — 0 сум, учтены в стоимости маш-ч.
