## Порядок использования
1. По каждому ресурсу просматриваются все файлы; применяется **максимальная** из сопоставимых цен (без НДС, в сумах, в одной единице).
2. Цены в USD — по курсу ЦБ на дату цены (курс указывать в примечании).
3. Источник цены указывается в ЛРВ (лист «Ресурсы»: кол. F кратко, G–L подробно).
