## Порядок использования
1. Каталог текущего квартала → местный рынок → зарубежный рынок (цены из `из_ЛРВ/` и `экспертиза/` — как подтверждённые ранее/экспертизой).
2. Цены без НДС, в сумах. Цены в USD — по курсу ЦБ на дату цены (курс указывать в примечании).
3. Сведения о применённой цене — в `База_цен.xlsx` (лист «Цены») со ссылкой на файл и строку.
